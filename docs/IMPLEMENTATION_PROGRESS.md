第5版では採用した一組の配置を先に成立させる。旧案の3配置制作を先に進めず、広場戦とランキングを初期公開の必須条件として残す。

検査の実施範囲と残件は [TEST_REPORT.md](TEST_REPORT.md)、今回の判断は [DESIGN_DECISIONS.md](DESIGN_DECISIONS.md) に記録する。`ACCEPTANCE_TESTS.json` は計画全体の検査仕様であり、ファイルが存在するだけで全検査の実行済みを意味しない。

R2aは8武器のデータ読込、P1の検証済み操作命令、実物の取得・装填、射手・設備・48更新共有枠、区間迎撃、分裂、同更新開始時の外装への着弾、補給妨害時計、入口減速の係数、4役割の判断を扱う。画面は従来の配置確認用のまま。補給は自動生成せず、検査では現物を明示配置している。

次のR2bでは、[接続契約](RULE_ENGINE.md) に従って実移動・突進の最初の接触から内部イベントを生成する。敵の移動目標・自衛・退避は現在は意図だけであり、移動や損傷に変換していない。広場横断には人物と生存世代・試合・出撃回を記録し、途中合流者へ無条件の通行権を渡さない。配送先の予約と運搬完了はR3まで未実装とする。

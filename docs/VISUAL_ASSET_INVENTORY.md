# セメコメ表示素材一覧・制作設計

2026-09-27。対象は第5版の採用対向配置一組。これは画像生成と表示実装の作業台帳であり、ゲームの人数・移動・勝敗条件や完成判定を変更しない。`docs/plans/current/AI_HANDOFF.md`、`PRODUCT_REQUIREMENTS.md`、`MAP_ADOPTION.md`、`SCREEN_FLOW_AND_BATTLEFIELD.md`、`SEVEN_PART_CORE_RULES.md`、`NPC_ROOMS_AND_RESPAWN.md`、`RESULTS_SCORE_RANKING.md`、`INTERIOR_LAYOUTS.json`を基準とする。

## 判定と制作境界

- **操作仮表示**：`src/presentation/battle-renderer.ts` / `battle-screen.ts`のCanvas/CSS図形・文字で実際の操作確認版に表示される。実画像は未導入。
- **配置仮表示**：`src/main.ts`のSVG配置プレビューに表示される。実戦の広場・敵陣の描画ができた意味ではない。
- **規則のみ**：ルールや状態は一部実装済みだが、該当の動くゲーム表示が未接続。
- **計画のみ**：通常戦の画面・状態として設計され、現状の表示はない。
- 下の「現在」は導入前のローカル`main`（6a8c4d7）の確認結果として保持する。**この時点では全項目とも生成画像は未導入**。今回のPRで追加した部分は後述の別表で示す。独自Canvas/SVG/CSSの仮表示を「生成画像あり」と数えない。
- 一組の自城は左・正面右、敵城は右・正面左。`INTERIOR_LAYOUTS.json`の自陣126×70セルを敵陣へ左右反転する。反転するのは床、壁、設備、向き。陣営状態、文字、左右の操作、人物配置の人数を反転共有しない。
- 部屋13室は両城共通の配置案（核以外12室）。復活室と核室は別。門G1〜G7は中央通路・復活室の後方から核へ至る唯一の通路に直列。一般の室間扉は7門ではない。外装P1〜P7は各城に独立した7部位であり、絵の装飾継ぎ目を追加の部位と解釈しない。

独自の工業用装甲城、丸い頭と短い脚の作業員ロボット、工業用ケースを**機械工房のミニチュア画風**で生成する。人物の造形は初期要件の「車輪台座・二本の作業アーム」から今回の表示上の補足案へ変更したもので、移動の操作・速度、当たり判定、P1〜P3と敵30人の人数へ影響させない。既存作品の画面、キャラクター、ロゴ、素材表を参照画像にした再現や名称だけの置換は行わない。装飾画像は画面の意味を奪わず、数値・短い日本語・形状による識別を併用する。

## 実装接続の順序と確認点

1. 22個の独立した画像の識別子・寸法・透過・用途と由来台帳を照合する。現行の寸法は21点が256×256px、`stage`だけ1200×600px。生成画像は衝突マップ、部屋や門の数値、物理判定を上書きしない。
2. 既存Canvas/SVGへ、床・人物・砲台・ケース・門・核の個別画像と状態読み取り表示を接続する。今回のPRの接続済み部分を確認し、将来の通常戦の敵陣/広場・観戦・結果へ段階的に広げる。画面切替ではゲーム状態を作り直さない。
3. 静止画像へ待機/所持/突進/保護/停止/破壊など必要な状態を重ねる。連番コマの歩行・攻撃アニメは現時点の提供範囲に含めず、開門・命中の演出完了を通行・勝敗判定の条件にしない。画面外の敵30人と飛翔物を描画省略してもシミュレーションは続ける。
4. アイコンだけで8種ケース・4役割・7部位・7門を読み分けられるか、短い日本語と数値を加えた小画面（360〜430 CSSピクセル）で確認する。外装全壊と核一撃の意味、広場突破、5秒観戦中の継続戦況、結果・ランキングの空/エラー状態を別々に検証する。

この文書の「仮表示」は素材制作の出発点であり、通常戦、ランキング接続、実機試遊、権利確認の完了を意味しない。

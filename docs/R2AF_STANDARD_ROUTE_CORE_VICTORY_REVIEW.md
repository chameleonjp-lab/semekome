# R2af 標準ルートで全7門を越え、有効なコア攻撃で勝利する

## 判定範囲

PR #67を取り込んだmain、commit `f2c05bff938adad237d4c25e3f9a88d8a2101343` を基準に、標準配分・固定seed `20260913`・通常初期配置でR2aeのルートを続けた。P1/P2/P3と広場警備に保護を付けず、敵AI・敵砲撃・補給生成・通常運搬も稼働させている。

今回は、P2/P3の通常支援射撃で敵外装P1〜P7を破壊し、開いたG1〜G7をP1が順に通過した後、P1自身の公開ダッシュ入力で敵コアへ有効な一撃を与え、標準条件の試合が `player_win` で終わることを確認する。コア接触や勝敗を直接注入せず、P1の通常移動・公開ダッシュから物理接触と勝敗判定までを通す。

## 結果

`tests/scenarios/r2v-standard-player-g1-infiltration.test.ts` の標準シナリオを match ID `r2af-standard-player-core-victory` へ延長した。P1は全7門の正規経路を保ったまま敵コア室へ入り、コア室内の敵を通常の公開攻撃で処理し、コア中心へ向けて公開ダッシュを送る。物理層の `bridge:core_contact`、共通勝敗判定へ届くP1の `core_hit_candidate`、敵コアの命中状態、`player_win`、終局イベント1件を確認した。

プレイヤー側コアは未命中で、敵30人の復活間隔は1,200 tick（20秒）のまま。外装7部位と門7つの状態、戦闘入力、コア接触をテストから直接変更していない。変更は統合シナリオと記録資料に限り、`src/`、画面、標準配分、射出間隔、AI設定は変更していない。

この固定seedでの一勝は実戦バランスの合格や、採用配置での複数回試遊を意味しない。支援射撃の `detour` 自動選択は未承認の補足調整として扱う。

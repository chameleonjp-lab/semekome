# R2ae 標準ルートでP7を破壊し、G7を越えてコア室へ入る

## 判定範囲

PR #66（R2ad）取り込み後のmain、commit `f6abad783486592cf1f082e7907a2b66beb429b0` を基準に、標準配分・固定seed `20260913`・通常初期配置で、G6通過後の標準ルートを延長した。P1/P2/P3と広場警備に保護を付けず、敵AI・敵砲撃・補給生成・通常運搬を稼働させている。

今回は、P2/P3の通常支援射撃がP7に実損傷を与えて破壊し、G7を開いた後にP1が全7門を通って敵コア室へ入ることを確認する。コアへ有効な攻撃は行わず、入室だけでは勝敗が変わらない境界も確認する。

## 結果

`tests/scenarios/r2v-standard-player-g1-infiltration.test.ts` の標準シナリオを match ID `r2ae-standard-player-g7-core` へ延長した。P6破壊後にP2/P3が正の外装損傷値を持つ `detour` 支援弾をP7へ発射し、追跡した支援弾の着弾更新でP7の実損傷・破壊が起き、G7が開くことを確認した。P7の破壊済み状態と開門を直接注入していない。

P1は開いたG7を通り、`currentRoomId` が `core`、`pathGates` がG1〜G7の状態で停止する。両陣営のコアは未命中で、試合結果は `ongoing` のままである。最終状態の破壊済み外装はP1〜P7、開門はG1〜G7。

## 変更範囲

標準ルートシナリオと記録資料のみを更新した。`src/`、画面、標準配分、射出間隔、敵30人・各1,200 tick（20秒）復活の実装は変更していない。支援射撃の `detour` 自動選択は未承認の補足調整のままであり、この標準seedでの到達を実戦バランス合格とは扱わない。

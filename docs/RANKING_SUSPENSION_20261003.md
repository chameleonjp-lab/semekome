# ランキングの一時停止（2026-10-03）

利用者の最新指示「指示があるまでランキングは停止する」を優先する。従来資料の「初期公開にランキング必須」は停止中には適用しない。明示の再開指示があるまで再有効化しない。

## 実施した本番停止

既存の `public.games.is_active` を、登録済み `semekome_standard_v1` の1行だけ `false` に変更し再読取した。共有RPC、RLS、権限、他ゲームは変更していない。既存の得点履歴1件、プレイ記録2件、集計1件は変更前後で保持した。削除・テスト得点登録・公開コードの配備はしていない。

現行RPC定義の読取と、`anon` ロールのトランザクション検査（必ずROLLBACK）で、新規開始・途中中止・結果の受付は `accepted:false / game_not_available` を返すことを確認した。得点登録は既存のinactive条件を最初に検査し、書込前に拒否する。上位取得もinactiveを拒否する。

既存開始IDの完全一致再送だけは、停止判定前に過去の受付を返す既存仕様がある。これは新しい開始・得点の書込ではない。終了・得点登録は停止条件で拒否される。既に開いている旧ページ・キャッシュ版は通信を試す可能性があるため、バックエンドの受付停止とクライアントからの要求停止を混同しない。

## この変更のクライアント停止

`loadRankingRuntime()` は環境設定・クライアント生成・localStorage読取より前に終了する。実キーが配備環境にあっても開始、結果、途中中止、再送、上位取得を起動しない。古い保留記録を消さず、そのまま保持する。画面には一時停止と外部送信しないことを表示し、ローカルの得点・結果・再戦は利用できる。

停止解除を環境変数やブラウザ設定から行う機能は設けない。再開には利用者の明示指示を受け、現在のゲーム規則・得点条件・古い保留記録の扱いを再レビューした別PRが必要。停止中の記録を自動で遡及送信しない。公開workflowや移行に再有効化処理は追加しない。

# R2p 標準主人公の広場到達レビュー

## 判定範囲

R2o後の次の小単位として、標準配分の実初期配置で、主人公P1が公開 `direction` / `handle` だけで自陣の補給ケースを1個拾い、砲台へP1を1回配送し、外装への発射を待たずに正面通路から広場へ到達する経路を固定した。敵・味方の通常AIは停止させず、P1、P2、P3、広場警備E25〜E27にテスト用の保護を加えていない。

P1の広場到達時には、実際のAI更新で登録された敵側の広場警備世代 `{ E25: 0, E26: 0, E27: 0 }` を確認する。到達だけを判定対象とし、敵城側への突破、警備との戦闘、7部位・7門・核・終局はこの単位へ混ぜない。明示的な `bridge`、座標越境、警備登録の直接注入は検査入力に使わない。

## 対象ファイル

- `tests/scenarios/r2p-standard-plaza-entry.test.ts`：固定seedの標準配分で、公開拾得・配送・移動からP1の広場到達、未保護の実初期状態、敵側警備世代を確認する。
- `docs/R2P_STANDARD_PLAZA_ENTRY_REVIEW.md`：判定範囲と非対象範囲を独立記録する。
- `src/`：今回のPRでは変更しない。R2oまでの物理移動・AI・広場出動契約を、標準主人公ルートから再検証する。

## 完了条件

- 標準配分が採用されたまま、P1が公開入力で実床ケースを1個拾い、`P1` を1回配送する。
- P1、P2、P3、E25、E26、E27へ保護fixtureを追加せず、P1が最初の広場到達時点で生存している。
- 広場到達時に敵側の実警備世代が登録され、P1の入力から `bridge:plaza_entry` や敵城側の通過権を生成しない。

## 非対象

標準配分での一戦勝利、広場警備の戦闘・突破、残りの外装と門、核接触、敵味方30人全員の通常行動、正式な味方命令の優先順位・対象指定・別室救援、正式結果・得点・ランキング、iPhone実機・試遊、公開作業はこの単位の完了条件に含めない。

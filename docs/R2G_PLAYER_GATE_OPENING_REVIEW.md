# R2g 主人公の公開砲撃・G1開門境界の独立レビュー

対象はPR #41取り込み後の主人公通常操作の次の小単位である。P1が公開 `direction` / `handle` だけで4回の通常配送を行い、砲台から敵外装P1へ実際に弾を当ててG1を開けた後、広場警備を公開 `dash` で撃破して敵城へ入り、開いたG1を越えた先の閉じたG2で止まることを追加回帰検査で確認した。明示的な `bridge`、座標越境、門開放、外装破壊、核接触の入力は使っていない。mainへの直接push、マージ、公開承認はこのレビューの範囲外である。

## 発見と確認

|観点|確認内容|結果|
|---|---|---|
|公開入力|補給・砲台受渡し・標的指定は公開 `direction` / `handle`、広場警備との接触は公開 `dash`、G1越境後の移動は held `direction` を使う|確認済み|
|砲撃境界|P1が4回の公開配送を行い、プレイヤー側の実発射が選択した敵外装P1を保持する|確認済み。`projectile_launched` と `destroyedPartIds` を確認|
|門の開閉|敵外装P1だけが破壊され、`openGateIds` は `G1` だけになる|確認済み|
|越境後の経路|P1が `central_corridor` → `respawn` → `corridor_0` → `corridor_1` を通り、`pathGates` は `G1` だけになる|確認済み|
|次の閉門境界|G2の手前で停止し、同じ公開方向を120更新続けても固定座標が変わらない|確認済み|
|fixtureの意味|敵AIは保護し、広場3防衛者は一接触で倒せる固定fixtureとした。戦術移動・体力バランス・敵砲撃を今回の合格条件から分離した|確認済み。通常戦全体の証拠ではない|

## 検査結果と残る境界

今回の差分は、既存の物理砲撃・外装・門・移動処理を主人公の公開入力から一つの境界へ接続する回帰検査と資料であり、本番コードは変更していない。固定小数点の経路終点が authored waypoint から最大50サブユニット手前で停止する既存物理境界に合わせ、検査の経路ヘルパーだけに50サブユニットの許容を置いた。

採用配置での通常体力・警備AI、残り6部位とG2〜G7、広場戦術全体、核接触、終局、味方命令、正式結果・得点・ランキング、iPhone実機・試遊はこの単位の合格範囲に含めない。G1開門fixtureを主人公の通常戦一戦走破やR2全体の完成証拠へ読み替えず、残件は [公開チェックリスト](RELEASE_CHECKLIST.md) を正とする。

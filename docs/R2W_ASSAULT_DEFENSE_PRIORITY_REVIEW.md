# R2w 越境成立後の敵反攻優先度レビュー

## 判定範囲

R2vでP1が敵城側へ越境した後、E29/E30がプレイヤーの一時的な位置だけでなく、成立済みの敵城側越境履歴を見て判断できる境界を確認する。初期状態では従来どおり敵侵入班のコア侵攻を許し、プレイヤーが敵城へ入った後は、P1が別室または広場へ離れても、E29/E30が古いコア突進を再開しない。

## 調整したAI

- 共通AIと物理AIの `canAssault` 条件に、対向側の越境記録が成立していないことを追加した。
- 越境記録の意味を統一した。`enemyCrossings` はプレイヤーが敵城へ入った記録、`playerCrossings` は敵がプレイヤー城へ入った記録として扱う。
- E29/E30の初期侵攻経路、敵30人、敵復活1,200 tick（20秒）、外装7部位・門7つ、通常接触損傷2、ダッシュ人物損傷1は変更していない。
- 広場警備の復活世代は自城の復活地点へ戻る既存仕様を維持し、旧世代の突破権を復活世代へ持ち越さない。

## 完了条件

- 越境記録がない初期状態で、E29/E30は `assault` を選ぶ。
- プレイヤー側の敵城越境記録がある状態で、E29/E30は `assault` を選ばない。
- R2vの標準配分・通常初期配置・公開入力によるG1越境と `corridor_1` 到達が継続する。

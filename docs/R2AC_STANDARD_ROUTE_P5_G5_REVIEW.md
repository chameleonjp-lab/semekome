# R2ac 標準ルートでP5を破壊し、G5を越える

## 判定範囲

PR #64（R2ab）取込後のmainを基準に、標準配分・固定seed `20260913`・通常初期配置の戦闘を続けた。P1/P2/P3と広場警備に保護を付けず、敵AI・敵砲撃・補給生成・通常運搬を止めていない。公開操作でP1がG1〜G5を順に越え、P2/P3の通常支援射撃がP5へ実損傷を与えて破壊し、G5開門後にP1が `corridor_5` へ入るところまで確認した。

## 確認内容

- R2abのP4破壊・G4開門・G4通過を維持し、P1がG5まで公開操作で進む。
- P4破壊後にP2/P3の支援弾が `detour` 経路でP5を狙う。損傷0の `screen_panel` 着弾だけでは合格にせず、P5の着弾更新に発生した実損傷と、その後のP5破壊を確認する。
- P5破壊後にG5が開き、その後にP1が `corridor_5` へ入り、通過履歴がG1〜G5の順で残る。
- 外装破壊はP1〜P5、開門はG1〜G5までに限られ、戦闘は継続する。

検査は既存の `tests/scenarios/r2v-standard-player-g1-infiltration.test.ts` を延長した。人物・外装・門の状態を直接変更せず、P1は公開方向・行動入力を使う。支援弾の対象順や外装と門の固定対応は直接注入せず、戦闘イベントと状態から判定する。

# R2ad 標準ルートでP6を破壊し、G6を越える

## 判定範囲

PR #65（R2ac）取り込み後のmain、commit `54375dc5fe1a4990d0fa59e1fa0eb00a1fffa1b3` を基準に、標準配分・固定seed `20260913`・通常初期配置で、前段R2acのG5通過から標準ルートを延長した。P1/P2/P3と広場警備に保護を付けず、敵AI・敵砲撃・補給生成・通常運搬を稼働させた。

今回の範囲は、P2/P3の通常支援射撃がP6に実損傷を与えて破壊し、G6が開いた後にP1がG6を通って `corridor_6` へ到達すること。人物・外装・門の状態を直接変更せず、公開入力によるP1操作を続けた。

## 結果

`tests/scenarios/r2v-standard-player-g1-infiltration.test.ts` の標準シナリオを match ID `r2ad-standard-player-g6-corridor6` へ進めた。P5破壊後にP2/P3が正の外装損傷値を持つ `detour` 支援弾をP6へ発射し、その弾の着弾更新でP6の実損傷・破壊とG6開門が成立した。固定更新19913で着弾、実損傷、P6破壊、G6開門を記録し、26更新後の19939でP1が `corridor_6` に入り、`pathGates` はG1〜G6となった。

最終状態では破壊済み外装がP1〜P6、開門がG1〜G6で、戦闘は継続している。支援弾の着弾だけを成功条件にせず、着弾更新のP6損傷、破壊、開門、P1の通過を順に検査する。P6の損傷と破壊は同じ固定更新に起きる。

## 変更範囲

標準ルートシナリオと記録資料のみを更新した。`src/`、画面、標準配分、射出間隔、敵30人・各1,200 tick（20秒）復活の実装は変更していない。支援射撃の `detour` 自動選択は未承認の補足調整のままであり、この標準seedでの到達を実戦バランス合格とは扱わない。

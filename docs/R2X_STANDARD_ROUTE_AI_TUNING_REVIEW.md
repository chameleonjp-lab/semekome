# R2x 標準ルートの補足値・敵味方AI調整レビュー

## 判定範囲

R2vとR2wの統合済み変更を含む標準配分・seed `20260913`・通常初期配置を基準に、G1通過後も通常ルートを壊さないための補足値と敵味方AIの優先順位を調整した。公開P1入力、実床ケース、敵味方の通常更新を使い、人物・外装・砲台・補給を検査用に直接完成状態へ変更していない。

今回の完了範囲は、R2vのG1通過とR2wの敵反攻優先度を維持しつつ、敵侵入の継続、支援員の護衛終了後の帰還、暫定砲撃ペースを固定するところまでである。残り6部位・6門、核・終局、標準一戦の勝利、実機・試遊は完了条件に含めない。

## 調整内容

- `physical_battle.enemy_launch_cooldown_ticks = 72` を通常ルート検査用の未承認補足値として追加した。共通の砲撃定義にある48更新枠と分離し、物理戦の敵側共有射出枠だけへ適用する。自陣の共有射出枠、敵の砲台4基、敵30人、敵1人あたり1,200更新（20秒）復活は変更しない。
- E29/E30は、主人公が敵城にいるという位置情報だけでは侵入を停止しない。広場は越境中の競合空間として扱い、通常の内部兵や広場警備の局所防衛は残す。正規の越境権が確定した場合は、R2wで定めた敵側の防衛優先を維持する。侵入兵が相手城内へ入った後は、支援員を見ただけで外国室に停滞せず、現在の門状態に応じたコア経路を継続する。
- P2/P3は、P1が広場にいる間は従来どおり護衛へ参加できる。P1が敵城へ入って残りの外周部位がある間は、護衛へ移らず砲撃・補給を優先する。P1が敵城内で倒れた場合、敵城内・広場に残った支援員は正面入口を通って自陣へ戻り、通常の防衛・砲台運用・補給へ復帰する。同室の敵防衛と明示的な `hold` 命令はこの帰還より優先する。

いずれも初期提案を承認済み仕様へ昇格させるものではなく、実測と試遊で再評価する暫定調整である。

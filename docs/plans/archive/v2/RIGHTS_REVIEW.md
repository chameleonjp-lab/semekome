# 権利・素材・公開表示の確認手順

第2版 / 2026年9月8日 / 確認手順であり、個別の権利確認結果ではない。

## 1. 目的

既存作品の具体的表現と未許諾素材の持ち込みを避ける。仕組みを一般化して新規制作する方針は、非侵害を自動的に保証するものではない。名称や数値の変更割合によって合法と判断しない。

## 2. 素材を追加する前

画像、音、文章、フォント、コードについて、作成者、入手元、使用条件、加工範囲、表示義務を記録する。原作から抽出・録音・画面転記したものは採用しない。AI生成の場合も入力資料、指示、出力、加工、類似確認を記録する。既存作品の固有名詞を隠して同じキャラクターを再現する指示は使わない。

## 3. 公開前

正式名称とロゴについて、同一表記だけでなく読み方や対象商品・サービスも確認する。完成した画面と音は個別の部品だけでなく、構成全体で見る。疑義があれば差し替えまたは必要な専門家への相談を行う。必要な特許確認は、具体的機能と対象地域を明示して行う。本資料では個別の特許請求範囲・権利状態は調べていない。

作品紹介に公式な続編・移植・関連作と思わせる表現を用いない。「非公式」や「ファン作品」の表示を、素材使用の許可に代わるものとしない。

## 4. 確認状態

|対象|現在|次に行うこと|
|---|---|---|
|正式名称|未定・未調査|名称決定後に類似名称と使用範囲を確認する|
|画像・音・文章|未作成・未確認|由来台帳を付け、新規制作と結果確認を行う|
|ライブラリ・フォント|未採用・未確認|実装時点の版とライセンスを記録する|
|個別特許|未調査|具体的な機能が固まった段階で必要な確認を行う|
|完成画面の全体表現|未作成・未確認|公開候補を一式で確認する|

根拠資料はSOURCES.jsonのL01〜L06。一般論の確認と、この作品の個別判断を混同しない。

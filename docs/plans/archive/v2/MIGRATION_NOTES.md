# 前版からの変更

第2版は、ユーザーの「2作目の戦車戦闘に限定し、戦闘要素を要件化して別のゲームにする」という指定を反映する。

## 維持する設計目的

運搬を砲撃へつなげる。攻撃資源で迎撃する。仲間に仕事を任せる。侵入で敵の作業を妨げる。耐久を失っても直接制圧まで抵抗できる。この五つを新しい要件として維持する。

## 撤回する条件

原作の数値一致、フレーム比較、全アイテム・全仲間・全戦車の収録、既存の室内図、既存の操作の完全一致、原作の不具合の再現、船バトルの差分、対戦を含む原作戦闘全体の完成という条件を撤回する。

## 実装に渡さないもの

旧版のAMMO_CANDIDATES.json、CREW_CANDIDATES.json、原作値のVERIFICATION_CASES.json、その他の名称対応表を本番データに変換しない。本一式には含めていない。過去の調査を削除していないかのように装うのではなく、資料保管と制作入力を分ける。

## 新たに提案するもの

車輪型作業ロボット、左右2枠・重量3、配分8による循環補給、一つの装填口と2経路、ケースの修理転用、装甲0後の2制御盤作業、独自の8ケースと3車内配置を提案する。これらは著作権上の安全性を数値で証明する変更ではなく、遊びと表現を新規設計する提案である。

完成判定はPRODUCT_REQUIREMENTS.mdとREQUIREMENTS.jsonを使い、旧版の再現率を使わない。

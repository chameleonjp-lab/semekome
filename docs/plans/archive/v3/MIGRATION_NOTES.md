# 第2版から第3版への変更

2026年9月8日。ユーザーが指定した「外装パーツ7つ→門7つ→コアへの攻撃」を勝敗の正本にする。

## 撤回する条件

単一の装甲360、装甲0で2制御盤を解禁する方式、制御盤ごとの2.5秒作業、空手での作業条件、制御盤の作業進捗と中断、2盤完了の勝敗を撤回する。これらをコアの別名や隠れた追加条件として残さない。

## ユーザー指定を反映する条件

双方の車両に独立した外装7部位、門7つ、コア1つを設ける。新しく1部位壊れると門1つが開く。全7門開放後にコア室へ入り、敵コアに有効な攻撃を1回当てれば勝つ。自車も同じ条件で敗北する。外装全壊は即敗北ではない。

## 補足案として追加した条件

各外装50、合計350を仮値とする。破壊順は自由で入口側の門から順に開ける。破壊済み外装は直せず、未破壊部位の修理だけ許可する。部位目標は装填時に記録し、壊れていれば着弾更新開始時点の未破壊部位へ代替する。余剰損傷は他部位やコアへ流さない。コアは突進の一撃とし、長押しと空手制限を設けない。仲間も同条件で攻撃可能。同更新の両コア命中は引き分けとする。これらの細部は個別承認済みと扱わない。

2作目の戦車戦闘から一般化した運搬・迎撃・分担・侵入・逆転という目的、独自の素材と表現、一人用、補助員2体、2枠運搬、補給配分、2砲撃経路、独自ケース8種、車内配置3種、対戦設定6種、練習3段階、iPhoneでの操作を維持する。船・原作の数値再現・既存アイテムの一対一移植は対象外のままとする。

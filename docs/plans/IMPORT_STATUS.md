# 計画資料の格納範囲

対象リポジトリ：chameleonjp-lab/semekome。対象資料：この会話で作成・添付された第1〜第4版の計画一式。

## 格納する内容

4つの元ZIPを開き、計画本文・引き継ぎ文・要件・初期設定・検査計画・敵名簿・部屋接続・権利確認資料など、48ファイルのMarkdown・JSON・Pythonを原文のまま保存します。第1版7件、第2版11件、第3版13件、第4版17件です。元の外側フォルダー名だけを、最新版は `current/`、過去版は `archive/v1/`〜`v3/` へ整理しています。

README・目次・AGENTS・この案内・IMPORT_MANIFESTは、リポジトリで迷わず資料を使うために追加した文書です。原文のゲーム仕様や数値は改訂していません。

## 含まれていない形式

**原本PDF4点と配布ZIP4点は未格納です。** 本文と付属データの内容を省略した意味ではなく、これらのバイナリ原本の転送が完了していないためです。元PDF・ZIPは会話の添付に残っています。別のPDFを再生成して原本と表示することはしていません。

## 実施する確認と、実施していない確認

転送用データのSHA-256を確認してから48ファイルを展開し、全JSONの構文、各ファイルの保存後ハッシュ、版ごとの件数を確認します。第4版付属の資料検査は一時コピーで実行し、原本の検査記録を上書きしません。今回の実行結果と日時は `IMPORT_MANIFEST.json` に別記録します。

ゲームのコード実装、115件のゲーム受け入れ検査、試遊、iPhone実機確認、性能計測、個別の権利調査は行っていません。計画内の `not_run` は未実施のまま維持します。

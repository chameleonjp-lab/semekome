# 外装7部位・7門・コア一撃の勝敗仕様

第4版 / 2026年9月9日 / 勝敗仕様を維持・敵部屋と復活仕様を追加 / ゲーム未実装

## ユーザーが指定した条件

両戦車は外装パーツ7つ、コアまでの門7つ、コア1つを持つ。異なる外装を1つ破壊するたびに門が1つ開く。全7門が開いたらコア室へ入れる。敵コアに有効な攻撃が1回当たれば勝利し、自車コアも同条件で攻撃されれば敗北する。

**外装の全壊だけでは決着しない。コア室への入室だけでも決着しない。攻撃が実際に当たって初めて決着する。** 以前の制御盤2つを停止する方式は撤回し、長押し作業や追加のコア耐久は置かない。

## 戦闘の流れ

外装の破壊数が0なら門はすべて閉じる。1部位壊せば1門、3部位なら3門、6部位なら6門が開くが、最後の1門がコア室への侵入を防ぐ。7部位を壊して全門を開けた後、敵車内を進み、コアへ近距離攻撃を当てる。

自車の門がすべて開いても、コアを攻撃されるまでは補給・砲撃・移動・防衛を続ける。味方に射撃を任せてコアを守る、侵入者を押し退ける、相手側のコアを先に狙うといった逆転を残す。

## 実装に必要な補足案

以下はユーザー指定を補う初期案であり、個別承認済みの条件ではない。

|項目|補足案|
|---|---|
|門を開く順番|外装の破壊順によらず入口側から1門ずつ開く。特定のパーツと特定の門を固定対応させない。|
|外装の耐久|各50の7部位。合計350は表示用で、単一体力として扱わない。|
|壊れた部位|戦闘中は復元しない。開いた門も閉じない。未破壊部位と通常設備だけ修理できる。|
|コアへの有効攻撃|行動可能な敵対作業員の突進。主人公・補助員・敵は同条件。荷物を持っていても可能。|
|無効な接触|歩いて触れる、扱うボタン、味方、車外砲撃、壁越し、門越し、復帰保護中の攻撃。|
|同時命中|同じ時間更新で両コアが有効な攻撃を受けた場合は引き分け。|

門7枚はコア室へ至る通路に直列で配置する。作業区画への侵入は開始時から可能だが、コア室へ回り込む別経路は作らない。突進や押し退けでも閉門を越えられない。敵車の複数の作業・戦闘室へ門を無理に詰めず、中央警備室からコアへの別の連続区画として作る。

## 判定の取り違えを防ぐ

開いた門数は破壊済み外装の一意な数から求める。同じ外装への追撃や重複通知で門を2枚開かない。一撃の余剰損傷で複数部位へ連鎖損傷させない。一更新で別々の部位が同時に壊れた場合は、その部位数だけ開く。

最後の外装を壊した更新では開放状態を確定し、通過と新しいコア攻撃は次の更新から認める。演出の終了を通行条件にしない。有効なコア攻撃と攻撃者の戦闘不能が同じ更新に成立した場合は、先に認めた命中を取り消さない。修理作業と違って継続時間はない。

外装、門、コアの状態は各車両が独立して持つ。コア攻撃を受けた車両側が負けることを、プレイヤー用・敵用で別実装しない。通常の時間切れ判定は従来の引き分け案を維持するが、その更新で成立したコア命中を先に確定する。

## 表示と説明

外側には7部位の損傷・脱落を見せ、車内では門の開放を見せる。「敵外装 4/7破壊」「自車の門 2/7開放」のように数字の意味を付ける。7門開放時にはコアが攻撃可能になったことを、音を消していても伝える。部位選択が必要な場合は、7つの小さい絵の直接タップを強要しない。

## 第4版の敵30人との関係

敵の討伐数は門にも勝敗にも加えない。30人の人物が20秒後に復活しても、外装・門・コアは戻さない。コア室へ初期配置・常駐・復活を設けず、開門後の防衛者は元の室から歩いて到達する。自車の敗北条件は同一だが、自車側の人数や復帰時間まで今回30人・20秒に確定したわけではない。詳細はNPC_ROOMS_AND_RESPAWN.mdを参照する。

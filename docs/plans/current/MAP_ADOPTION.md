# 採用図と移動マップ / 第5版

## 採用した内容
ユーザーが「これ、採用です」と指定した「城の向きと配置」を方向・主要配置の基準にする。自陣は左側で正面出入口が右、中央に広場、敵陣は右側で正面出入口が左。自陣は元の図面を右へ90度回転した配置、敵陣はその左右反転であり、敵だけ90度回転した別構造にはしない。上画面と下画面で方向を変えない。
採用図の主要室は、前側に砲台A・Bと弾薬庫A・B、後側に砲台C・Dと弾薬庫C・D、中央の上に修理室、下に指令室、中央通路の後側に復活地点、前側に正面出入口がある。文字は正立させる。

## 図にない確定ルールを消さない
採用JPEGは向きの確認図であり、核室と7門が省略されている。既定の外装7部位・門7つ・核一撃は撤回されていない。移動用平面図では後方に専用の核室と7門の通路を補い、復活室を核室へ置き換えない。核への別入口、裏口、復活ワープは設けない。追加部分の寸法と位置は補足案である。
画像の各扉を7門と読み替えず、外装破壊で開くのはG1〜G7だけ。通常室の行き来は城内の全員討伐を要求しない。広場での突破条件は別の状態で管理する。

## 補足案と変更理由
旧版の6砲台・2弾薬室では採用図のA〜Dと一致しないため、現行の配置案を両城4砲台・4弾薬庫へそろえる。これはユーザーが別途「4基」と数字を指定した事実ではなく、採用図に合わせた実装案である。敵は4射手・4護衛・8運び手・14内部兵で計30人とする案に変更し、総数30と各人20秒は変更しない。
自陣の人数はまだプレイヤー1人＋補助員2人の案。鏡写しの対象は床・壁・部屋・設備・向きであり、人数や体力状態をコピーする意味ではない。完成マップはまずこの一組を優先し、旧3種類の配置案は将来の追加候補へ移す。新しい広場戦闘とランキングを、配置違い3種の制作より先に成立させる。
INTERIOR_LAYOUTS.jsonは126×70セルの自陣側の設計座標。セルは床の制作単位で、プレイヤーは連続移動する。敵側のセルは(125-x,y)、矩形は(126-x1,y0,126-x0,y1)、向きは(-dx,dy)で生成する。文字や画面の操作は反転せず、独立した城番号を割り当てる。
採用図の部屋の相対位置を保つ一方、壁厚・通路幅・砲台占有床・復活床の安全性は実ゲームで確かめる。添付図が承認されたことを、当たり判定や実機性能の合格にしない。裏側の砲台も上空の共通砲撃経路へ発射するので、城内や復活室へ直接弾を飛ばす描写にはしない。

## 保存形式
approved/ADOPTION_RECORD.jsonで今回の添付JPEGの名前・寸法・SHA-256を特定する。GitHubには縮小プレビューを保存し、原寸JPEGは会話添付の原本として識別値だけを記録する。縮小画像から微細な当たり判定を推測しない。
drawings/04_CASTLES_FACE_EACH_OTHER.svgは、採用した向きと核室・7門を併記した文字を読める構造図。描画用のゲーム素材ではなく、配置の補助説明である。旧案の6砲台図や向きの異なる画像を現行の基準へ混ぜない。

# 画面・現在地・広場・復活の仕様 / 第5版

## ホームから開始まで
ホームの主要操作は「ゲーム開始」「ルール説明」。ルールはホーム上に重ねるモーダルで、閉じると元のホームへ戻る。閉じるボタンと背面の誤操作抑止を設ける。
ゲーム開始→名前登録→カウントダウン→開始を固定する。名前は前後空白除去後1〜20文字を共通規約に合わせる。空白だけでは開始しない。名前欄へ前回値を入れても、開始時に確認する。20文字の数え方と正規化は接続先と実装時に照合する。
カウントダウン3秒は補足案。カウントダウン中は戦闘時計・射撃・復活時計を進めず操作を受け付けない。中止ならホームへ戻り、二重押下でも試合を重複生成しない。名前確定・開始処理成立の一度だけ開始記録を作り、失敗した開始や中止した準備を試合数へ水増ししない。
初期公開は一人用。編成はゲーム開始前の任意設定とし、標準値で始められる。練習はルールモーダルから選べる案とし、競技記録と分ける。

## 現在地で表示を切り替える
自陣にいる間は自陣の移動用マップ、広場では左に自城・右に敵城・中央に地上の戦闘・上空に砲撃、敵陣では自陣を左右反転した移動用マップを表示する。別エリアを表示しても同じ試合の人物・砲撃・補給・復活を継続する。切替は人物の境界通過で一度だけ行い、シーン再生成で世界を戻さない。
全画面で自城は左、敵城は右という基準を維持する。敵陣に入っても操作の右入力を左移動へ反転しない。反転するのは地形・設備・向きであり、文字や操作ボタンではない。城の損傷、人物や物体は別々の状態を持つ。
自陣・敵陣の室内表示は人物の周囲を追い、移動先と出口が読める大きさにする。全図を画面へ無理に縮めない。戦況帯で外装7部位、破壊数、門の開放数、核の危険を常に確認できる。
ゲーム画面は表示領域へ固定し、ページのスクロールで動かない。操作領域は48 CSSピクセル以上を提案し、切り欠き・下端を避ける。ルール・名前入力・結果は必要な範囲だけ内部スクロールできる。30人分の体力表示でマップを埋めない。

## 広場を突破する条件
敵城の通常室への侵入は外装破壊前でも可能。ただし広場の敵を倒して通過するという新指定を先に満たす。城内30人の全滅と、核を守る7門とは別の条件である。広場の守備者を無視して出口へ走る、突進ですり抜ける、画面を切り替えて敵を消す方法では通過させない。
詳細は補足案として次のようにする。敵30人中E25〜E27を広場警備へ派遣し、E29・E30を侵入任務に使う。開始時は担当室にいて徒歩で出る。追加の31人目を作らず、討伐後20秒で元の担当室へ戻って再び移動する。広場警備数3は未承認の初期配分である。
自陣から広場へ出た人物または同行班ごとに一回の横断記録を作る。警備担当の現在の生存世代と、広場にいる生存敵を対象に記録する。まだ移動中の警備担当も対象なので到着前に通過できない。すでに倒され復活待ちの者は、その試合の実際の討伐記録で処理済みとする。逃走・範囲外への押し出し・描画停止は討伐ではない。
未突破の間に新しい敵が広場へ入れば対象へ加える。自陣へ侵入済みの敵や、ほかの城内の全員まで倒す必要はない。同じ時間更新の戦闘・死亡・広場への入場・復活を解決した後、対象が全員討伐済みなら突破済みにし、次の更新から敵陣側出口へ進める。
突破後は後続の復活で許可を取り消さず、人物を引き戻したり閉じ込めたりしない。復活した敵は通常の攻撃で妨害できる。自陣への退却はいつでも可能。自陣へ戻るか本人が倒れたら許可を破棄し、再出撃時は新しく判定する。同行者の対象番号と生存世代は出撃時に固定し、後から来た仲間へ永久通行権を配らない。
敵の侵入班にも同じ原則を使い、広場の生存味方を倒す必要がある。味方が一人もいなければ通過でき、主人公が敵陣にいるだけで敵の進軍を停止させない。敵は徒歩で自陣の通常室へ入り、設備妨害と条件成立後の核攻撃を行う。

## プレイヤーが倒れた場合
体力0を確定した更新dから300更新＝5秒後に自陣の復活室へ戻る。これはユーザー指定。敵30人の1200更新＝20秒と分離し、補助員の復活時間は引き続き補足案として管理する。
5秒間は暗転や停止画面にせず、中央の広場と両城の損傷・上空砲撃を観戦できる。観戦中も味方・敵・弾・外装・門・核の状態は進む。移動、攻撃、装填、命令の操作は受け付けない。荷物は討伐地点に落とし、復活時は体力全快・荷物なしという補足案を使う。
5秒で自陣表示と移動操作を戻す。復活後1秒の攻撃・作業不可の保護時間は補足案であり、復活待ちを6秒に延ばす意味ではない。核室や閉じた門の奥へ復活させない。5秒の観戦中に核が破壊された場合は直ちに結果へ移り、予定復活を破棄する。
明示的な一時停止やアプリ非表示では戦闘全体と両者の復活時計を止める。観戦中も同じ。復帰は再開ボタンから行い、非表示時間の追いつき処理をしない。死亡による観戦は一時停止ではない。

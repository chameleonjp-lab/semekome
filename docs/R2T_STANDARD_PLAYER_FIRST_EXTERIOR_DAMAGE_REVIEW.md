# R2t 標準配分で敵外装P1へ実損傷を与えるレビュー

## 判定範囲

R2sで固定した標準配分・公開P1対象・敵砲撃干渉の更新列をそのまま使い、敵外装P1へ実際の損傷が入る境界を4,200更新で検査した。P1/P2/P3には保護を付けず、P1は実床ケースを取得し、公開 deliver で detour ルートと敵外装P1を選ぶ。

この単位で確認したのは次の境界である。

- projectile_launched の実イベントで、公開選択した detour とP1対象が保持される。
- player projectile が敵外装P1へ到達し、part_damaged の team=enemy / partId=P1 を発生させる。
- 敵外装P1のhealthが初期値より下がる。
- P2/P3の通常運搬と、敵砲撃による未保護の自陣外装損傷が同じ更新列で成立する。
- 門は外装の破壊状態に連動し、外装損傷だけでは開門しない。

## 判定と残件

R2tは、標準条件の公開砲撃が敵外装へ実損傷を与えることを固定した bounded run である。これは外装P1の破壊、G1の開門、広場警備の撃破、敵城内進入、標準一戦の勝利を確認するものではない。

標準条件で最初の外装破壊までを含む長い経路では、敵勝利が先に確定する試行が残っている。次は、R2tで確認した実損傷からP1破壊・G1開門へ進む経路を、火力・敵砲撃・復活・敵味方行動の実測に合わせてさらに分ける。

## 非対象

7部位・7門・核・終局、正式な味方命令の優先順位・対象指定、敵味方30人全員の通常行動、相互侵入、結果・得点・ランキング、iPhone実機・試遊、公開作業はこのレビューの合格範囲に含めない。

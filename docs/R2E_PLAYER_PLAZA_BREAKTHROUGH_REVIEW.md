# R2e 主人公の公開突進による広場突破の独立レビュー

対象はPR #39取り込み後の主人公通常操作の小単位である。P1が公開 `direction` / `handle` / `dash` だけで広場へ進み、広場のE25〜E27を撃破した後に敵城へ入れることを、既存の物理・共通境界と回帰検査の読取で確認した。mainへの直接push、マージ、公開承認はこのレビューの範囲外である。

## 発見と確認

|観点|確認内容|結果|
|---|---|---|
|公開入力|補給・砲台受渡し・広場移動は公開 `direction` / `handle`、警備との接触は公開 `dash`、撃破後の越境は held `direction` を使う。明示的な `bridge` や座標越境入力は使わない|確認済み|
|防衛者集合|E25〜E27を出動世代として登録し、全員を広場へ配置して順に接触する。各防衛者はこの単位の境界を短く保つため一接触分の体力に限定する|確認済み。体力バランス・複数回接触は非対象|
|越境判定|3人の `alive` がすべて `false` になった後、P1の通常方向入力で敵城へ入り、`enemyCrossings["P1:0"].allowed` を確認する|確認済み|
|AIとの分離|対象外の敵は保護し、対象警備も各接触まで固定する。警備AIの移動や敵側の自動勝利はこのテストの証拠に含めない|確認済み|
|既存境界との整合|R2dの未撃破警備による停止、R2cの世代付き出動・復活・再侵入、既存の物理ダッシュ接触検査を変更せずに追加した|確認済み|

## 検査結果と残る境界

今回の範囲では重大な未解決所見はない。R2e局所回帰8/8、全Node回帰274/274、資料57/57、型検査、製品ビルド、差分空白検査、Quality #170のChromium/WebKit 50/50を通過した。ローカルのブラウザ実行環境制約とは提出版CIを分離して記録する。

採用配置での主人公の運搬・迎撃・砲撃から7部位破壊、広場戦術全体、7門、核接触、終局、味方命令、正式結果・得点・ランキング、iPhone実機・試遊はこの単位の合格範囲に含めない。体力を短縮した固定fixtureを通常戦全体の完成証拠へ読み替えない。

ブラウザ用のスキルに従って確認を開始したが、agent-browserは起動時に失敗したため、Playwrightで代替した。ローカルは既存Chromium 143を指定し、WebKitはCI側の結果と分ける。自動テスト中の編集によるページ再読み込みを避けるため、テスト専用サーバーではHMR（変更の自動反映）を無効化した。移動量の比較は時計を明示停止し、位置読取と指を離す操作の間に実時間の1更新が混ざらないようにした。

固定seed 20260913の25,000更新（戦闘時間416.7秒）の通し検査では、P1が通常入力で4回運び、自陣81発・敵436発・迎撃139回。最終発射は自陣24,904更新・敵24,975更新で、終盤20,000更新以降も両側が継続した。由来・所持枠・受渡し・待ち列・飛翔体の一意な所在を毎更新確認した。両側への実ダメージを確認し、外装・門の7段階は専用ルール検査と分担した。自陣7門開放・敵0門というこの固定操作の結果はバランス合格ではない。24往復や両城全壊をこの操作列の成立条件にはしない。1000更新の計測は約1.6秒、25,000更新の監査付き検査は約55秒であり、iPhone実機FPSを表す値ではない。

今回の検査で扱うのはR2aの部分条件である。`ACCEPTANCE_TESTS.json` 全135件を実行済みに変更しない。実機性能、試遊・ゲームバランス、名称・素材の権利確認、公開、外部ランキング接続は未実施のまま。

自動画面検査では360×640、390×664、402×700、430×932、844×390を使用した。主要ボタン48px以上、画面外へのはみ出し、部屋選択・説明の表示、ルールダイアログの閉鎖とフォーカス復帰を確認した。配置画面は戦闘時計を進めない。

ローカル環境ではPlaywright標準ブラウザの取得に失敗したため、Chromium 143を指定して検査した。ローカルのWebKit検査は未実施。CIのブラウザ検査はローカル結果と分けて扱う。

### R1のレビューで確認した修正点

コア命中を確定する内部イベントの境界、試合ID・生存世代を欠く入力の拒否、飛翔体と運搬物の参照、予約の解放、両城の待ち列の独立性を修正した。発射後の待ち列を詰め、同じ場所へ重複して入らないことも検査した。図の後方通路と実床を整合させ、両城の7門をそれぞれ一枚だけ閉じた14通りで核への道が遮断されることを検査した。

資料に残る旧設備数と未実装の表記、自陣人物の重なり、設備と復活床の表示、役割ごとの図形識別を修正した。

自陣3人の復活床を配置JSONに統一し、コードによる追加生成を廃止した。人物と初期室・復活室・担当床の対応も設定時に検査し、核室への不正な床移設や床の欠落を拒否する。門の回帰検査は各人物の初期室と復活床が属する室を対象とした。

固定seed 20260913の25,000更新（戦闘時間416.7秒）の通し検査では、P1が通常入力で4回運び、自陣80発・敵428発・迎撃136回。最終発射は自陣24,960更新・敵24,894更新で、終盤20,000更新以降も両側が継続した。由来・所持枠・固定受渡し枠・待ち列・飛翔体の一意な所在を毎更新確認した。両側への実ダメージを確認し、外装・門の7段階は専用ルール検査と分担した。自陣7門開放・敵0門というこの固定操作の結果はバランス合格ではない。24往復や両城全壊をこの操作列の成立条件にはしない。1000更新の計測は約1.4秒、25,000更新の監査付き検査は約53秒であり、iPhone実機FPSを表す値ではない。

CIで開始の二重タップが切替直後の中止ボタンへ当たる不具合を検出したため、切替直後350msの中止入力を無視し、初期表示・操作遮断を初回描画待ちにせず適用した。名前・中止検査の時計を明示停止し、停止中40秒の検査は不要な全描画を再生せず時間経過だけ進める形へ変更した。停止中の更新不変と、再開時に過去時間を追いつかせない条件は維持した。最終レビューでは、受渡し2枠の実位置、装填時の最新経路・部位、重量制限を含む表示候補と実際に拾う弾の一致も回帰検査した。

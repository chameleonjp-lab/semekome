# R2aa 標準ルートでP3を破壊し、G3を越える

## 判定範囲

PR #62（R2z）の取込後を基準に、標準配分・固定seed `20260913`・通常初期配置の戦闘を続けた。P1/P2/P3と広場警備に保護を付けず、敵AI・敵砲撃・補給生成・通常運搬を止めていない。公開操作でP1がG2を越えた後、P2/P3の通常支援射撃がP3を破壊し、G3が開いた後にP1がG3を越えるところまで確認した。

## 確認内容

- 標準配分と敵味方の通常行動を保ち、P1が公開操作でG1・G2を順に通過する。
- G2通過後、P2/P3の支援弾が `detour` 経路でP3を狙う。損傷0の `screen_panel` 着弾だけでは合格にせず、実損傷後のP3破壊を確認する。
- P3破壊後にG3が開き、その後にP1が `corridor_3` へ入り、通過履歴がG1・G2・G3の順で残る。
- 敵外装の破壊はP1・P2・P3、開門はG1・G2・G3までに限られ、戦闘は継続する。

検査は既存の `tests/scenarios/r2v-standard-player-g1-infiltration.test.ts` を延長した。人物・外装・門の状態を直接変更せず、P1は公開方向・行動入力を使う。P3とG3に固定対応があるとは仮定せず、破壊済み外装数と入口側から開く門の連動を確かめる。

# R2y 標準ルートのP2破壊・G2開門レビュー

## 判定範囲

PR #60（R2x）取り込み後の `main` を基準に、標準配分・固定seed `20260913`・通常初期配置から、P1がG1を通過した後の次の外装・門を検証した。P1/P2/P3と広場警備を保護せず、敵AI・敵砲撃・補給生成・通常補給運搬を停止していない。

変更前の診断では、敵外装P1の破壊とG1通過後もP2/P3が敵側へ有効な着弾を作れず、試合上限の25,200更新で引き分けた。敵側ではP1だけが破壊され、P2〜P7とG2〜G7は未完了だった。

## 調整内容

- 敵外装が1部位以上破壊され、まだ全てのコア経路用ゲートが開いていない間、プレイヤー側の `support` が自動配送する補給ケースを `detour` 経路へ設定する。
- 敵砲台が通常使う `direct` 経路との相殺を避け、標準AIの配送・自動装填・発射の流れで次の生存外装を攻撃する。
- P1の公開操作、標準配分、対象部位の順序、敵射撃間隔、敵人数・復活時計は変更しない。オペレーターによる明示的な経路・部位選択は引き続き優先する。

## 検査

`tests/scenarios/r2v-standard-player-g1-infiltration.test.ts` を標準通常ルートの継続検査として延長した。同じ通常初期配置からP1が公開操作でG1を越えた後、P2/P3の通常運搬による `detour` 発射、敵側への着弾、P2破壊、G2開門を検査する。シナリオはP2破壊が反映された更新で停止する。

R2yシナリオ1/1、全Node回帰302/302、資料57/57、`npm run build`、`git diff --check` を通過した。画面変更がないためChromium/WebKitは未実施。iPhone実機・試遊は未確認である。

R2yで確認したのはP2破壊とG2開門までである。P1はG1を越えた `corridor_1` に残り、G2通過は次の検証に残す。P3〜P7、G3〜G7、核・勝敗、標準一戦の勝利、実戦バランス、正式結果・ランキング、ブラウザ・iPhone実機・試遊は未確認である。

`detour` 自動選択は敵砲台との経路競合を避ける暫定調整であり、実機・試遊後に再評価する。標準一戦の勝利や実戦バランス合格へ読み替えない。

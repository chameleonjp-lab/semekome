# R2r 標準広場警備3人の通常撃破と敵城側越境レビュー

## 判定範囲

R2qで確認した標準配分・敵味方稼働・保護fixtureなしの広場到達と初回通常接触攻撃から続け、主人公P1が公開入力だけで広場警備E25〜E27へ通常接触攻撃を繰り返す。各警備の現在位置と接触可能な対象は物理側の現在スナップショットから取得し、検査側は座標・体力・警備ID・保護状態・通過権を入力へ渡さない。

3人の世代0を撃破した後、P1が右方向の公開移動を続け、広場の通過判定が世代付きの警備状態を確認して敵城側へ入れることを確認する。撃破のために敵味方の保護を追加せず、警備を停止・配置・回復させない。

## 対象ファイル

- tests/scenarios/r2r-standard-plaza-breakthrough.test.ts：標準配分の実床拾得・1回配送・広場到達・通常接触攻撃・3人撃破・敵城側越境を、1つの公開更新列で確認する。
- docs/R2R_STANDARD_PLAZA_BREAKTHROUGH_REVIEW.md：判定範囲と非対象範囲を独立記録する。
- src/：今回の単位では変更しない。R2qまでの物理人物損傷・AI警備・広場通過判定を、標準配分の連続更新で再検証する。

## 完了条件

- P1が標準配分の実床ケースを1個拾い、公開入力で1回配送して広場へ到達する。
- E25〜E27が通常AIで登録された世代0のまま、公開通常接触攻撃でそれぞれ設定済みの体力を失い、3人とも撃破される。
- 3人の生存警備がいない状態で、P1の公開方向入力だけが敵城側への越境を成立させる。
- 越境記録がP1の世代0に対して許可され、勝敗は核への有効な突進まで継続する。

## 非対象

敵城内の7部位・7門・核、標準一戦の勝利、敵味方30人全員の通常行動、警備以外の侵入敵との戦闘、正式な味方命令の優先順位・対象指定・別室救援、結果・得点・ランキング、iPhone実機・試遊、公開作業はこの単位の完了条件に含めない。

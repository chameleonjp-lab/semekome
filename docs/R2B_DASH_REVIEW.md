# R2b 突進接続の独立レビュー

対象：PR #35後の主人公突進UI、核の物理接触、観戦復活の入力境界、簡易終局表示。設計確認と独立レビューはSol High、UI実装と回帰追加はLuna Max、統合時の同時移動・部分拒否の是正と全体検査は主担当が行った。通常戦全走破や公開可否の最終承認ではない。

|発見|是正と確認|
|---|---|
|核室内にいるだけで突進が核命中になる|核室中心への連続区間接触を検査。入室・空振り・歩行・味方核・閉門・保護中を除外。接触距離1.17床は補足案|
|観戦中のP1意図と入力消去が世界更新を妨げる|観戦中は意図なしで更新。入力解除と時計リセットを分離し、300更新の復活と保護後の新規入力を検査|
|キーリピート・失われたkeyup・横画面の重複|移動repeat抑止、Spaceクリック重複抑止の解除、横向き配置を修正。複数指・AT相当クリック・6画面サイズで検査|
|一括接触で1件拒否されると有効分まで消える|共通処理のinputIndexで拒否分だけ除外。HP1への同時接触で死亡と復活予定を維持|
|同方向・同速度の突進が人物ID順に依存|全員の開始位置・速度から相対移動を計算し、最早接触まで同時に進める。650サブユニット間隔の追走は両順序で無接触|
|斜め接触を整数に丸めるとbridgeが拒否|人物接触も最大2サブユニットの丸め誤差を許容。560.115の接触で損傷成立|
|核距離の説明と実装値が不一致|1,170サブユニットへ説明を統一。表示の装飾半径とのピクセル一致は主張しない|
|公開bridgeが同じ人物の実突進命中を上書きする|その更新で突進を物理計算した人物を記録し、公開bridgeの重ね合わせを拒否。守備者への先行命中と本物の核命中を、新規/継続突進の両方で保持する回帰を追加|

先行の限定再レビューは上記の同時接触3再現、壁で停止した後の接触、核命中と別接触の一部拒否、両核同時命中を再確認した。提出前の追加レビューで公開bridgeによる実接触の上書きを発見し、上表のとおり是正した。世界時計は1更新、両核同時は引き分け・終局イベント1件を確認した。全体の件数とブラウザ/CIの状態は [検査記録](TEST_REPORT.md) を正とする。

是正後のSol High限定再レビューで、守備者の先行命中、本物の核命中、最終更新の空振りを再現確認した。公開bridgeの重ね合わせによる上書き・取消は解消し、単独bridgeの経路を維持している。この限定範囲に新たな重大所見なし。初期公開全体の承認とは扱わない。

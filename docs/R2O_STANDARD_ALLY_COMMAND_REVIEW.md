# R2o 標準通常戦への味方命令接続レビュー

## 判定範囲

R2nで追加したP2/P3の `hold` / `supply` 命令を、保護fixtureではなく標準配分の実初期配置へ接続した。P2/P3は無保護のままとし、P1の公開入力から各支援型を一度停止し、解除後に通常の補給運搬へ戻せることを確認する。

同じ試合でP1は既存R2kの公開ルートを進み、4,200更新までに実際の床ケースを4回以上配送する。P2/P3の運搬と敵砲撃による自陣外装への干渉も同時に観測する。命令対象はP2/P3のIDと `hold` / `supply` の種別だけで、座標・敵ID・別室救援経路は入力へ追加しない。

## 対象ファイル

- `tests/scenarios/r2o-standard-ally-command-route.test.ts`：標準配分、P2/P3の停止・解除、P1の公開配送、味方運搬、敵砲撃干渉を一つの固定seedで確認する。
- `src/simulation/physical-battle.ts`：今回のPRでは変更しない。R2nの命令境界が標準条件でも成立するかを統合検証する。

## 非対象

標準配分での一戦勝利、広場突破の実戦バランス、命令の優先順位・対象指定、別室救援、敵味方30人全員の通常行動、正式結果・得点・ランキング、iPhone実機・試遊、公開作業はこの単位の完了条件に含めない。既存のR2n局所境界とR2kの4,200更新bounded runを、通常戦全体の完成へ読み替えない。

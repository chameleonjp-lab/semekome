## 完成と取り違えない範囲

今回の検査は、既存 PR #34 の戦闘確認画面と第5版目標の差分を記録する。通常の一試合全体の画面遷移、名前登録・開始カウントダウン・420秒上限に至るゲーム成立、勝敗後の結果/得点表示、上位10位と共有ランキング接続は別の未実装・未検証範囲であり、素材の見た目を整えても達成扱いにしない。プレビューにある7外装・7門・核、両陣営、敵30人20秒復帰と主人公5秒観戦復帰の仕様は維持し、今回の表示修正を理由に人数や条件を減らさない。

全 Node 検査238件（25,000更新のシナリオを含む）、Chromiumスマホ条件15件、資料57件、型検査・製品ビルドを通過した。独立レビューの追検24件も通過。スマホ5サイズの操作領域・説明文の非重複、日本語画像付き390×844画面、画像失敗時の操作を確認した。ブラウザでの固定状態確認は [状態一覧](art-preview/audit-states.png)、[ホーム](art-preview/audit-home-390x844.png)、[操作画面](art-preview/audit-match-390x844.png) を参照する。GitHub Actionsの最終CI結果はPRに記録する。

長時間負荷での実画面性能、子弾の実機視認性、iPhone17Proでの減速輪・核/門の可読性と操作感は未評価。通常戦全体の導線・結果・ランキングも完成範囲に含まない。追加の個別素材IDは必要なく、第三の山上城が描かれた `stage` を画像生成した `stage-v2.webp` に差し替えた。個別エフェクト、開門、核解除、子弾、床ケース、減速領域は既存画像と状態連動のコード描画で補完した。

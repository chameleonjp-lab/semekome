# R2v 標準ルートでG1を越えて敵城内へ進入するレビュー

## 判定範囲

R2uでの標準配分による敵外装P1破壊・G1開門から続け、P1が公開入力のみで広場警備E25〜E27を通常攻撃で撃破し、敵城へ入り、G1を越えて `corridor_1` へ進む経路を検査する。seedは `20260913`、標準補給配分、通常配置を使い、人物の体力・位置・保護、外装・門、砲台の発射状態はテストから直接変更しない。

P1は公開 `handle` / `direction` / `attack` / `dash` を使って4回配送した後に広場へ向かい、公開された接触対象を通常攻撃してG1を通過する。P1離脱後はP2/P3が待ち列のある味方砲台を運用する。敵味方の行動、砲撃・飛翔・着弾、補給運搬は通常更新のまま進める。敵城内への支援員同行はこの結合検査では合格条件にしない。

## 調整した補足値・AI

- 未承認の通常接触損傷値を `normal_contact_damage = 2` として独立管理する。ダッシュ人物損傷 `dash_actor_damage = 1` は変えない。
- P2/P3はP1が離れた砲台の待ち列を引き継ぐ。生存中の別オペレーターや、同じ支援タスク中の別支援員がいる砲台には重複して向かわない。
- P2/P3はP1離脱後、待ち列のある砲台を引き継ぐ。同室の侵入敵への局所防衛および明示的な `hold` 命令の優先順位は既存の別シナリオで維持する。
- E29/E30はプレイヤーが広場または敵城にいる間、直ちにコアへ向かうよりも現在の侵入への対応を優先する。侵入が終われば通常の敵AI判断へ戻る。
- 広場警備の復活世代は自宅で復活し、復活処理だけでは旧世代の出撃登録を更新しない。対向側が一度越境した後、復活警備を広場へ再出撃させて突破口を再封鎖しない。世代不一致の通過権は再利用しない。
- 敵30人、各人の20秒復活（1,200 tick）、外装7部位・門7つと開門順、標準補給配分は維持する。

## 完了条件

- 4回以上の通常配送、砲台を離れた後のP2/P3発射、敵外装P1の破壊とG1開門が同じ試合内で成立する。
- P1が公開通常接触攻撃で3人の広場警備へ致死量の実損傷を与え、敵城側へ越境する。
- P1が公開方向でG1だけを越えて `corridor_1` へ進む。
- 最終状態でP1は敵城内におり、`pathGates = ["G1"]`、敵側の開門集合は `["G1"]`、勝敗は継続中である。
- 広場警備の出撃登録が現行世代を参照し、復活世代が旧世代の通過状態を引き継がない。対向側の越境後は復活世代が突破口を閉じ直さない。

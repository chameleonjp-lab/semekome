# R2s 標準配分の公開砲撃対象と敵砲撃干渉レビュー

## 判定範囲

R2rで確認した広場突破の後続として、標準配分の公開砲撃を、敵砲撃が稼働する実初期配置で4,200更新だけ検査した。P1/P2/P3へ保護を付けず、通常の床ケース取得、砲台への配送、砲撃選択を公開入力の direction / handle として送っている。

この単位で固定したのは次の境界である。

- 本番標準配分（標準弾3、重量弾2、防護弾2、高速弾1）を createBattle からそのまま使用する。
- P1は公開 deliver で detour ルートと敵外装P1を選択し、projectile_launched の実イベントでその選択が保持されたことを確認する。
- P1の実床拾得、4回以上の配送、P2/P3の通常運搬、敵砲撃による未保護の自陣外装損傷、敵側への着弾境界を同じ更新列で確認する。
- 敵城側の openGateIds は destroyedPartIds と同じ外装接頭列だけから生じ、テスト入力から門を直接開けない。

## 判定と残件

R2sは、標準配分の公開砲撃が敵砲撃干渉下でも、公開選択したP1対象を保持して発射へ進むことを固定したbounded runである。P1外装の破壊、G1の開門、広場警備の撃破、敵城内への進入、標準一戦の勝利は完了条件に含めていない。

標準条件で最初の外装・門まで一気に走らせた試行では、敵勝利が先に確定する経路が残った。このため、砲撃対象選択と敵砲撃干渉を、外装破壊・門通過・核接触・終局とは別の責任範囲として記録する。次の単位で、同じ標準条件の火力・迎撃・復活・敵味方行動を含めた敵城側の残り経路を、実測に基づいて再分割する。

## 非対象

正式な味方命令の優先順位・対象指定、敵味方30人全員の通常行動、相互侵入、結果・得点・ランキング、iPhone実機・試遊、公開作業はこのレビューの合格範囲に含めない。

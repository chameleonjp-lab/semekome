# R2q 標準広場警備への初回通常接触攻撃レビュー

## 判定範囲

R2pで確認した標準配分・敵味方稼働・保護fixtureなしの実初期配置から続け、主人公P1が公開 `direction` / `handle` で実床ケースを1個拾い、砲台へP1を1回配送して広場へ到達する。その後、通常AIが広場へ出動させたE25〜E27のいずれかがP1と実際に接触できる位置へ来たとき、公開 `attack` を1回だけ送る。

攻撃は現在の同じ広場・人物接触を共通の `actor_contact` へ渡し、警備者へ設定済みの一回分損傷を与えることを確認する。P1の位置が攻撃で変わらず、突進を開始せず、戦闘が継続することも確認する。警備登録・人物位置・体力・保護状態を検査側から直接注入しない。

## 対象ファイル

- `tests/scenarios/r2q-standard-plaza-combat.test.ts`：標準配分の公開拾得・1回配送・広場到達から、実警備への初回通常接触攻撃を確認する。
- `docs/R2Q_STANDARD_PLAZA_COMBAT_REVIEW.md`：判定範囲と非対象範囲を独立記録する。
- `src/`：今回のPRでは変更しない。R2iの通常接触攻撃とR2pの標準広場到達を、一つの標準更新列へ接続して再検証する。

## 完了条件

- P1が標準配分の実床ケースを1個拾い、公開入力でP1を1回配送して広場へ到達する。
- E25〜E27の実AI出動世代のうち、P1へ最初に接触した警備者を攻撃対象として取得する。
- 公開 `attack` 1回で `bridge:actor_contact` が生成され、対象警備者の体力が一回分だけ減り、P1の位置・突進状態・勝敗状態が変わらない。

## 非対象

広場警備3人の全撃破、複数回接触の体力バランス、敵城側への突破、残りの外装・門・核・終局、敵味方30人全員の通常行動、正式な味方命令の優先順位・対象指定・別室救援、正式結果・得点・ランキング、iPhone実機・試遊、公開作業はこの単位の完了条件に含めない。

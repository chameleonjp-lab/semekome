# R2z 標準ルートでG2を越え、P3支援射撃の実損傷を確認

## 判定範囲

PR #61（R2y）をmainへ取り込んだ状態を基準に、標準配分・固定seed `20260913`・通常初期配置の同じ戦闘を延長した。P1/P2/P3と広場警備を保護せず、敵AI・敵砲撃・補給生成・通常補給運搬を動かしたまま、P1の公開操作でG2を越え、P2/P3の支援射撃が次の敵外装P3へ損傷を与えるところまでを確認する。

この変更では、シミュレーション本体・画面・配分・射出間隔・敵30人・各人20秒の復活を変更していない。既存の `tests/scenarios/r2v-standard-player-g1-infiltration.test.ts` を標準ルートの継続検査として延長した。

## 確認内容

- 通常初期配置からP1が公開操作で広場へ進み、広場警備3人を倒してG1を越える。
- P2/P3が通常の補給運搬・砲台操作を続け、P2を破壊してG2を開く。
- P1がG1、G2の順に越え、敵城内 `corridor_2` へ入る。
- G2通過後にP2/P3の自動射撃が `detour` 経路でP3を狙い、P3への着弾後に実際の耐久低下が起きる。
- P3はこの境界では未破壊で、G3は閉じたまま。戦闘も継続する。

P3へ最初に届く弾は、標準配分に含まれる `screen_panel` の場合があり、これは外装へ損傷を与えない。そこで検査は着弾だけで成功にせず、G2通過後のP3損傷も確認してから停止する。

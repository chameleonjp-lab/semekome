# R2u 標準配分で敵外装P1を破壊しG1を開門するレビュー

## 判定範囲

R2tと同じ固定seed（20260913）・標準配分・通常初期配置を使い、P1が公開操作で敵外装P1を初めて破壊する境界を検査した。P1/P2/P3を保護せず、敵側の人物、砲撃、味方運搬、敵AIの更新も止めていない。8,000更新を上限とし、敵外装P1が壊れた最初の更新で検査を終了する。

公開 `direction` / `handle` 入力で実床ケースを取得し、砲台へ配送する。配送では `detour` ルートと敵外装P1を選び、既存の射撃・飛翔・着弾・損傷処理を通す。外装health、破壊済み部位、門状態、人物の体力・位置・保護状態は検査から直接変更しない。

## 確認した事実

- プレイヤー側の実発射が公開選択した `detour` とP1標的を保持した。
- プレイヤー砲弾による敵外装P1への損傷イベントが発生し、P1のhealthが0になった。
- P1の破壊イベントは一度だけ発生し、対応する門はG1だった。
- 破壊後の状態は `destroyedPartIds = ["P1"]`、`openGateIds = ["G1"]` で、敵外装の他の部位・門は未破壊・閉鎖のままだった。
- シナリオは固定seedの5,970更新目で停止し、その時点で `phase = running`、`outcome = ongoing` だった。
- 同じ更新列でP2/P3の運搬と、敵砲撃による未保護の自陣外装損傷も観測した。

## 継続診断で見つかった境界

受入シナリオはP1破壊の直後に停止する。診断目的で同じseed・同じ操作を停止せずに続けた一時実行では、P1破壊とG1開門後も戦闘が続き、12,887更新目に `enemy_win` となった。この延長実行は今回の合格条件へ含めず、標準一戦の勝利や実戦バランスの根拠にはしない。今後は敵城内へ向かう標準操作と、双方の勝ち筋が同時に働く範囲を別に検査する。

# R2j 主人公の7部位・7門・核公開走破レビュー

## 判定

主人公P1が、公開入力だけで補給・砲撃・広場突破・敵城内の7門通過・核への突進まで進み、通常戦の勝利状態へ到達する物理境界は成立した。

ただし、これは勝利経路を固定するためのNodeシナリオである。敵味方の通常行動、標準配分の難易度、iPhone実機、正式結果画面、得点、ランキングを完了した証拠ではない。

## 今回確認した事実

- P1は補給口から実ケースを取得し、公開 `deliver` と実砲撃で敵外装P1〜P7を順に破壊する。
- 7部位の破壊は7つの接頭列の門を開くが、外装全壊だけでは勝利しない。
- P1は広場のE25〜E27を公開突進で倒し、倒した世代に基づく通過権で敵城へ入る。
- P1は公開方向入力だけでG1〜G7を通過し、閉門で止まる物理経路を使って核室へ進む。
- P1の核への公開突進が実際の核接触を作ったときだけ、敵核が命中し、`player_win` と `ended` を一度だけ生成する。
- 終局後の公開入力ではtick、門、核、結果状態が変わらない。

## 検査の境界

今回のシナリオは、次の理由で実戦バランスの検査とは分ける。

- P1の配分は、7部位を短い決定的経路で検査するための高損傷4種（dense_payload 3、breach_lance 3、standard_slug 1、fast_dart 1）を使用した。
- P1以外の人物は保護状態にし、敵の砲撃・味方補助・敵AIの干渉で経路が変わらないようにした。広場の3警備者だけは、公開突進の対象として個別に解除した。
- 広場警備の体力は既存の公開突進境界fixtureと同じく、一回の接触で確認できる値にした。

したがって、標準配分での勝利時間、敵30人の行動・復活、味方命令、相互侵入、複数戦の継続は未判定である。今回の合格範囲は、公開入力が物理側の補給・砲撃・人物接触・門衝突・核接触を順序どおりに接続することに限る。

## 結論

R2jは、R2i後に残っていた主人公側の「全7部位→全7門→核への有効突進→通常戦勝利」の公開入力境界を追加するDraft PR候補である。通常戦全体の完成、正式結果・ランキング、実機確認、公開可否は別の残件として維持する。

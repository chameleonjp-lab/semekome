# semekome

車内での運搬・砲撃・迎撃・侵入・防衛を組み合わせる、独自のブラウザゲームの計画資料です。現在は要件定義・実装計画の段階で、ゲーム実装はまだありません。

## 最初に読む資料

**実装の基準は第4版です。** [全計画書の目次](docs/plans/README.md)から、最新版と過去版を確認できます。

1. [実装担当への引き継ぎ](docs/plans/current/AI_HANDOFF.md)
2. [要件定義・実装計画書 第4版](docs/plans/current/PRODUCT_REQUIREMENTS.md)
3. [外装7部位・7門・コア攻撃の仕様](docs/plans/current/SEVEN_PART_CORE_RULES.md)
4. [複数の部屋・敵30人・20秒復活の仕様](docs/plans/current/NPC_ROOMS_AND_RESPAWN.md)

## ユーザーが指定した条件

両戦車は外装7部位とコアまでの門7つを持ちます。外装を1部位壊すごとに門が1つ開き、全門開放後にコア室へ入れます。敵コアへの有効な攻撃1回で勝利し、自車コアも同条件で攻撃を受ければ敗北します。

敵車にはコア室以外にも複数の部屋を設け、砲台と役割を持つ敵30人を配置します。各人は討伐から20秒後に復活します。役割ごとの人数、部屋数、砲台数、自車の人数などは、計画書で補足案として区別しています。

## 資料の扱い

第1〜第3版は変更履歴として[archive](docs/plans/archive/README.md)に保管し、実装へ混ぜません。とくに第1版の原作再現用データは、現在の独自ゲームの実装入力ではありません。

計画本文と付属データは元資料の内容を変えずに格納しています。[格納範囲と確認結果](docs/plans/IMPORT_STATUS.md)を参照してください。原本PDF4点・配布ZIP4点はこの格納には含まれていません。

mainへの直接push・自動マージは行わず、変更は作業ブランチとDraft Pull Requestで提出します。マージ・公開はユーザーが判断します。

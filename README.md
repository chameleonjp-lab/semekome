# semekome / セメコメ

城同士の砲撃で外装7部位を破り、7つの門を開け、敵陣へ乗り込んで核を攻撃する独自ゲームです。現在は8武器の共通砲撃ルール・敵の判断基盤と、通常戦の開始から勝敗表示、人物接触時の主人公の近接攻撃、主人公側の7部位・7門・核への公開操作境界、主人公離脱中の味方支援型による同室防衛、P2/P3への守備・補給復帰命令、標準通常戦での命令統合、標準配分での主人公P1の広場到達と実警備への初回通常攻撃、広場警備3人の通常撃破と敵城側越境までを接続しています。終局結果とローカル試合記録は接続済みです。得点式・外部ランキングは未接続です。

R2ajでは、P2/P3へ続けて押しても二人への指示を保持し、待機中の指示を個別に取り消せるようにしました。攻撃と突進を同時に押したときも、先の行動と味方指示を保持します。範囲は [R2ajレビュー](docs/R2AJ_ALLY_COMMAND_QUEUE_REVIEW.md) を参照してください。

## 配置確認画面

ホームからルール説明を開くか、「配置を確認する」で自陣・広場・敵陣を確認します。地図はドラッグ・矢印キーで見渡せます。「見たい場所」で部屋を選択し、拡大・縮小・全体表示を切り替えられます。カメラを切り替えても人物や世界を再生成しません。

## 通常戦の操作

「通常戦を始める」から名前と補給4種類の配分を入力し、3秒のカウントダウン後に開始します。左のパッドを動きたい方向へずらすと移動（キーボードは矢印またはWASD）。床の弾の近くで右のボタンを押して拾い、通路を通って砲台へ運び、装填します。砲台の操作位置に立っている間だけ自動発射します。左・右の所持枠、次に装填する弾の経路・狙う外装、自車に次に届く2個を確認できます。勝敗表示まで同じ通常戦の状態で進みます。

開始位置の上に弾薬庫A、その隣に砲撃室Aがあります。右上の小地図は現在位置の確認用です。一時停止・画面離脱後は「再開する」で戻ります。「?」で操作説明を開くと戦場も止まります。砲台の待ち列が満杯のときは受渡し枠で待機し、発射で空きができると自動で装填します。名前は外部へ送信せず、架空のスコア・順位は表示しません。

敵と同じ広場または城内ルームで接触しているときは「近接攻撃」ボタン、Enter、Xキーで一回の人物損傷を与えます。対象がいないとき、復活保護中、観戦中、停止中は操作できません。コアへの勝利攻撃は近接攻撃ではなく、7門通過後の突進です。

「突進」またはSpaceは押し始めに1回だけ発動し、移動中は現在の方向、停止中は最後の移動方向へ進みます（初期は右）。再使用待ち・観戦・復活保護・停止中は発動しません。全7門を通った後、敵の核そのものへ突進を当てると勝利します。核室への入室や歩行接触だけでは勝利しません。

画面下の「味方」からP2/P3へ守備を指示すると、その支援型は現在位置を保持し、同じ物理空間で見えている敵だけを防衛します。反映前に同じボタンをもう一度押すと、その人への待機中の指示だけを取り消します。守備が反映された後は「補給へ戻す」で解除できます。二人への指示を続けて押しても両方届きます。停止・説明・観戦へ入ると待機中の指示は取り消されます。命令は生存中のP2/P3の世代に限り、別室・別城への救援経路は作りません。

敵の侵入班も、広場から自陣へ入り、開いた7門を通って自陣の核を突進で狙います。主人公や味方が広場にいる間は敵の入城を止めますが、自陣の内部にいるだけでは広場の通過を止めません。

## 開発と検査

Node.js 24とPython 3が必要です。

```sh
npm ci
npm run dev
npm run check:docs
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:browser
```

`npm run dev` は `http://127.0.0.1:4173` に配置確認画面を起動します。資料検査は通常、検査結果ファイルを書き換えません。GitHub Actionsは同じ検査とビルドを行い、確認用ファイルを成果物に保存します。公開は行いません。

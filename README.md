# semekome / セメコメ

城同士の砲撃で外装7部位を破り、7つの門を開け、敵陣へ乗り込んで核を攻撃する独自ゲームです。現在は8武器の共通砲撃ルール・敵の判断基盤と、4種の弾を使う運搬・砲撃の操作確認版があります。広場戦・侵入・核攻撃まで通した通常の対戦はまだ遊べません。

[計画書と図面の目次](docs/plans/current/README.md) / [実装担当への引き継ぎ](docs/plans/current/AI_HANDOFF.md) / [過去版](docs/plans/archive/)

現行は第5版。自陣は左、広場が中央、敵陣は右。敵30人は20秒で復活し、主人公は5秒の観戦後に自陣で復活します。画面・広場・スコア・結果・上位10位ランキングを計画へ反映しています。

実装範囲は [進捗](docs/IMPLEMENTATION_PROGRESS.md)、検査の実施範囲は [検査記録](docs/TEST_REPORT.md)、採用した補足案は [実装判断](docs/DESIGN_DECISIONS.md) を参照してください。ランキング未接続・実機未検査です。mainへ直接変更せずDraft PRで進めます。

直近の後続検査では、選択した補給ケースが共通の床生成からP1の取得・装填、共有発射枠、共通砲台の発射まで同じケースIDで進む境界を固定しています。移動AIや通常戦全体の完成を示すものではありません。

## 配置確認画面

ホームからルール説明を開くか、「配置を確認する」で自陣・広場・敵陣を確認します。地図はドラッグ・矢印キーで見渡せます。「見たい場所」で部屋を選択し、拡大・縮小・全体表示を切り替えられます。カメラを切り替えても人物や世界を再生成しません。

## 運搬・砲撃の操作確認

「運搬・砲撃を試す」から名前と補給4種類の配分を入力し、3秒のカウントダウン後に開始します。左のパッドを動きたい方向へずらすと移動（キーボードは矢印またはWASD）。床の弾の近くで右のボタンを押して拾い、通路を通って砲台へ運び、装填します。砲台の操作位置に立っている間だけ自動発射します。左・右の所持枠、次に装填する弾の経路・狙う外装、自車に次に届く2個を確認できます。

開始位置の上に弾薬庫A、その隣に砲撃室Aがあります。右上の小地図は現在位置の確認用です。一時停止・画面離脱後は「再開する」で戻ります。「?」で操作説明を開くと戦場も止まります。名前は外部へ送信せず、架空のスコア・順位は表示しません。

## 開発と検査

Node.js 24とPython 3が必要です。

```sh
npm ci
npm run dev
npm run check:docs
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:browser
```

`npm run dev` は `http://127.0.0.1:4173` に配置確認画面を起動します。資料検査は通常、検査結果ファイルを書き換えません。GitHub Actionsは同じ検査とビルドを行い、確認用ファイルを成果物に保存します。公開は行いません。

## 次の段階

R2aでは8武器を共通データから動かし、現物の取得・装填、射手の確認、共有発射間隔、迎撃、分裂、外装着弾をルール処理でつなぎました。4役割の敵は仕事の意図を選び、近くの取得・装填・砲台操作だけを実行します。詳しい境界は [共通ルールの接続契約](docs/RULE_ENGINE.md) を参照してください。

共通ルールのR3経路では、補給生成から配送予約・室間移動・待ち列投入までを追加し、予約後に砲台が停止した場合も配送先を再選択します。これは物理操作確認版の固定座標AIや画面導線とは別で、通常戦を通した完成ではありません。

操作確認画面は別の物理処理で、出撃前に選んだ4種類の弾を補給・移動・受渡し・装填・砲撃まで試せます。8武器の共通ルールと物理操作確認版は時計と状態を分離しており、共通側の全面配送や通常戦の終局へはまだ接続していません。PR #4の共通ルールを保持し、操作確認用の処理は `src/simulation/physical-battle.ts` に置いています。

PR #7では両処理の検証済み入力を物理の一更新へ接続し、PR #8ではダッシュの人物接触を1損傷・36更新無敵・荷物一個の落下・0.6床の押し戻しへ共通ルールと接続し、PR #9では1.2床を12更新で進む突進実行器と自動接触証跡、PR #10では敵設備への10損傷・耐久60・480更新停止と復旧、PR #11では内部兵の城内目標・局所防衛・退避、PR #28では出撃前補給配分の物理戦引き継ぎ、直近では共通WorldStateの床生成境界の回帰検査を追加しました。全人数と7門を維持し、R1の内部イベントを外部操作へ直接接続しません。共通ルール側の全面配送、実広場から通常戦終局までの完成、観戦・結果画面は残件です。公開とiPhone実機確認は未実施です。

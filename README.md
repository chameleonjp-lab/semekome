# semekome / セメコメ

城同士の砲撃で外装7部位を破り、7つの門を開け、敵陣へ乗り込んで核を攻撃する独自ゲームです。現在はR1の基礎モデルと配置確認画面を実装しています。通常の対戦はまだ遊べません。

[計画書と図面の目次](docs/plans/current/README.md) / [実装担当への引き継ぎ](docs/plans/current/AI_HANDOFF.md) / [過去版](docs/plans/archive/)

現行は第5版。自陣は左、広場が中央、敵陣は右。敵30人は20秒で復活し、主人公は5秒の観戦後に自陣で復活します。画面・広場・スコア・結果・上位10位ランキングを計画へ反映しています。

実装範囲は [進捗](docs/IMPLEMENTATION_PROGRESS.md)、検査の実施範囲は [検査記録](docs/TEST_REPORT.md)、採用した補足案は [実装判断](docs/DESIGN_DECISIONS.md) を参照してください。ランキング未接続・実機未検査です。mainへ直接変更せずDraft PRで進めます。

## 配置確認画面

ホームからルール説明を開くか、「配置を確認する」で自陣・広場・敵陣を確認します。地図はドラッグ・矢印キーで見渡せます。「見たい場所」で部屋を選択し、拡大・縮小・全体表示を切り替えられます。カメラを切り替えても人物や世界を再生成しません。

## 開発と検査

Node.js 24とPython 3が必要です。

```sh
npm ci
npm run dev
npm run check:docs
npm test
npm run build
npx playwright install --with-deps chromium webkit
npm run test:browser
```

`npm run dev` は `http://127.0.0.1:4173` に配置確認画面を起動します。資料検査は通常、検査結果ファイルを書き換えません。GitHub Actionsは同じ検査とビルドを行い、確認用ファイルを成果物に保存します。公開は行いません。
